Kopi Nusantara adalah usaha kedai kopi rumahan yang membutuhkan halaman website yang dapat diakses oleh calon pelanggan(user) melalui berbagai perangkat(mobile, tablet, dan desktop) tanpa kendala *scroll* horizontal. Halaman website ini juga dilengkapi dengan berbagai elemen interaktif untuk meningkatkan pengalaman user.

Fitur Utama :
- Desain Responsif : Menggunakan HTML5 dan CSS3 (Flexbox dan CSS Grid), memastikan UI rapi di semua perangkat.
- Interaksi Dinamis (jQuery):
  - Fitur 'Like' Menu: Tombol interaktif dengan penghitung angka (*counter*) dan animasi pada 8 menu Kopi Nusantara.
  - Accordion FAQ: Daftar pertanyaan pelanggan yang bisa dibuka-tutup, diatur agar hanya satu jawaban yang terbuka dalam satu waktu.
  - Smooth Scrolling: Navigasi halus saat mengklik tautan di *header* atau *footer*.
  - Popup Kontak: Notifikasi interaktif *overlay* saat pelanggan mengirimkan pesan dari formulir.
